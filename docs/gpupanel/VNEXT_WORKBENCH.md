# GPUPanel vNext 开发基线

2026-10-16，按用户提供的前端视觉与交互方案推进。定位为 GPU 工作站、AI 开发环境
与 Linux 运维管理平台：**Workbench-first、Infrastructure-ready、AI-assisted**。
本文是开发基线，不是全部功能已实现或已验收的声明。

## 产品目标与边界

一套设计系统，一个统一门户，两个主要工作视角：默认的个人工作站，以及资源与运维。
按价值依次完成：可运行的 GPU 开发环境、本地 AI 应用闭环、本机到远程主机管理。
常用操作直接可达，复杂配置放入高级详情；Agent/MCP 不占个人工作站一级导航。

复用已合入的 React 19、Semi、Redux/RTK Query 和 Go Core/Agent。浏览器调用
认证后的 Core，由 Core 代理 Agent；展示层不获得直接执行任意宿主机命令的权限。
桌面能力以后由显式适配接口接入；仓库当前没有 Wails v3 宿主，本轮不声称桌面端已接通。

对象术语见 [GLOSSARY](../../GLOSSARY.md)。项目是持久资产，工作区是绑定入口，
会话是运行实例；不能拿 Docker 容器列表填充“最近项目”。同一项目停止、换环境或
开启第二个工作区后，原始代码与数据仍属于该项目。

## 作用域与状态约束

顶栏始终显示当前主机及信息读取状态。当前没有节点注册/选择 UI，不把 SSH 资产
自动提升为受管节点。所有现有 HTTP 请求仍使用认证和 CurrentNode；终端 HTTP
探测与 WebSocket 使用同一 `operateNode`。页面容器按节点重新挂载，关闭旧日志、
详情与终端；助手草稿随节点切换清除，数据缓存沿用既有 scope reset。

后续节点选择器必须验证 enrollment/身份与当前权限后才提供可选节点。不可在页面
显示远程节点却将命令发到 local。受限或不可用能力要给出原因，不能静默回落本机。

统一任务设计沿用已有任务 ID 与结果核对原则：请求已受理、执行中、成功/失败、
UNKNOWN 分开。刷新后的查询以服务端任务记录为准；失去 ACK 时只允许查询对账，
不得自动二次安装。完整环境构建/模型启动的可恢复任务仍需后端接口和进程重启证据。

助手仅接收用户草稿，显示当前页面名称和主机名称，不自动收集日志、密钥或项目文件。
未来依次接入问答、辅助填写、受控执行；执行前必须展示目标、影响范围、确认记录，
由后端细粒度授权和独立结果观察执法。隐藏 Agent 配置不隐藏操作风险。

## 开发顺序与下一条真实闭环

| 批次 | 交付 | 进入下一阶段的条件 |
| --- | --- | --- |
| P0 Shell（本轮） | 统一导航、顶栏、主题、动作优先首页、能力状态、任务直达、助手侧栏 | 类型/构建、模拟浏览器和作用域负向检查通过 |
| P0 项目工作区 | 项目列表/详情、四步向导、环境启动停止、持久目录与 IDE | 在一次性 Ubuntu 上创建 Python 项目，重启后数据与会话可核对 |
| P1 应用/模型 | 审核模板、来源配置、模型部署/端点/日志/推理 | 安装、启动、真实调用、停止、卸载各有实际证据 |
| P1 AI | 上下文问答、日志解释、命令审批 | 真实模型元数据/预算/数据范围授权，危险动作无法绕过后端确认 |
| P2 企业 | 多主机、组织/RBAC、审计、可选 K8s | 单主机 G3–G6、身份作用域及多节点负向测试通过 |

下一轮的项目/环境契约需要先冻结以下内容，再实现 UI 写操作：

1. Core 持久记录项目 ID、属主和绑定的 Host，不允许浏览器提交任意宿主机路径或命令。
2. Agent 拥有批准的工作根目录、目录创建、环境运行和实际状态观察；模板确定版本及摘要。
3. Workspace 绑定 Project + Environment Template；Session 单独具有运行 ID、任务 ID、
   资源限制、日志和访问端点。删除会话不删除项目；删项目单独确认数据影响。
4. 四步向导依次选项目、模板、资源/持久目录、预览确认；CPU 为可验证默认，GPU
   分配须实际设备检测、兼容性检查及授权，不靠首页设备数量推断。
5. 创建/启停可取消、限时、幂等并可查询；ACK 丢失进入 UNKNOWN，服务重启后能对账。
6. 首条闭环选择 Python + Notebook/Terminal；真实 PyTorch/GPU、IDE、备份恢复逐项验收。

保留成熟 Host/Container 实现；按 app shell、features、shared components、services
渐进拆分，不为本轮视觉重构引入第二前端或破坏 `/api/v1`。
